# Remote Control — Liquid Fusion

Independent, offline-first LAN remote-control project. This GitHub repository is the canonical project source. The previous v0.8 code baseline and approved Liquid Fusion reference are being migrated and validated. **Do not treat the existing labs as a functioning remote-desktop APK.**
